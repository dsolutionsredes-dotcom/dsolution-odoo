# D-Solution WhatsApp Base

Módulo propio para Odoo Community 20.1 + OCA `mail_gateway_whatsapp`.

Incluye:
- ventana de 24 h desde el último mensaje del cliente;
- aviso visual en Discuss;
- bloqueo backend de texto libre fuera de ventana;
- botón **Enviar plantilla**;
- variables **Campo de Odoo** o **Texto manual**;
- soporte Guest/Invitado.

Primero debe instalarse y probarse en una base clon. No modifica Odoo core ni el módulo OCA.
