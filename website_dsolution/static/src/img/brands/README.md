- Canva, Meta, Google Ads, Google Analytics, Google Tag Manager, Adobe Photoshop, OpenAI, Anthropic, n8n, WordPress, Next.js, Wix, Blackmagic Design, OBS Studio, TikTok and Odoo: SVG brand marks downloaded from the Simple Icons package on 2026-09-27.
